# AI 使用记录模板

使用方法：每项任务记录实际使用情况，复制到 `00_Collaboration/ai_usage/记录编号.md`。需要保密的完整对话保存到经团队认可的位置，仅共享允许共享的部分。

- 记录编号、任务编号：待填写。
- 操作者、日期与时间：待填写。
- 工具名称、模型、可确认的版本：待填写；无法获取则标“未知”。
- 用途：待填写，例如方案比较、编程、调试、图表调整或文字修改。
- Skill 名称与版本：待填写；未使用则标“未使用”。
- 实际输入、附件及完整输出的保存位置：待填写。
- 被采用的内容及对应文件版本：待填写。
- 人工如何核查、修改或弃用：待填写。
- 尚未解决的问题：待填写。
- 可共享范围：待确认。

不要以摘要冒充完整输入输出，不补造历史记录。不同成员使用不同工具时分别登记。论文披露材料应依据真实记录整理，比赛提交前核对当届官方要求。
