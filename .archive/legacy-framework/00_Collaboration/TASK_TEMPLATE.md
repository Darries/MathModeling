# 任务与交接模板

使用方法：复制到 `00_Collaboration/tasks/任务编号.md`；不要直接填写这份空白模板。真实团队内容是否共享另行确认。

## 要做什么

- 任务编号、名称：待填写。
- 目标与完成标准：待填写。
- 状态：待开始 / 执行中 / 等待人工确认 / 阻塞 / 完成 / 需重新验证（选择一项）。
- 执行 Agent 或成员：待填写。
- 本次人工确认人、独立复核人：待指定；不等同于固定岗位。
- 所需资料、位置、版本、共享许可：待填写。
- 前置任务及必须先取得的确认：待填写。
- 使用的 Skill、版本、软件：待填写。

## 人工确认记录

按需要填写；AI 不得代签。确认必须指向具体版本，不能只写“通过”。

| 决定 | 涉及文件与版本/校验值 | 确认人 | 时间 | 结论与条件 |
| --- | --- | --- | --- | --- |
| 研究方向 | 待填写 | 未确认 | 待填写 | 待确认 |
| 数学假设与方案 | 待填写 | 未确认 | 待填写 | 待确认 |
| 实验结果与可用结论 | 待填写 | 未确认 | 待填写 | 待确认 |
| 最终交付 | 待填写 | 未确认 | 待填写 | 待确认 |

本任务不涉及的项目写“不适用”并说明理由。确认后发生输入、参数或假设变更时，标明受影响任务和产物“需重新验证”；假设变更先取得新确认，保留旧记录。

## 实际执行与检查

- 实际执行步骤、命令、输入版本：待填写。
- 输出位置和版本：待填写。
- 实际检查及日志位置：未运行。
- 错误、失败尝试、未解决问题：待填写。
- AI 使用记录位置：待填写。

## 交给下一位成员或 Agent

- 已完成且有证据支持的内容：待填写。
- 下一步可做的事：待填写。
- 仍须等待确认的事项：待填写。
- 下游任务和需要同步的文件：待填写。

文件更新只保存在本地时，不标记“已同步给团队”。
