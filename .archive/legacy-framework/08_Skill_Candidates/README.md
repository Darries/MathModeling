# 待审查技能线索

此处只收集链接和说明，不是可执行技能目录。未审查的脚本不运行，也不放入 `.agents/skills`。

## 按用途找技能

| 分类 | 存放内容 |
| --- | --- |
| [01_Environment 环境与协作](01_Environment/README.md) | 环境配置、Git、任务协调和交接 |
| [02_Research 题目与资料](02_Research/README.md) | 题目分析、文献检索、资料整理 |
| [03_Modeling 数学建模](03_Modeling/README.md) | 假设、模型比较、优化、预测和评价 |

分类表示“做什么”，状态表示“能不能用”。每个候选记录分别填写主分类、辅助标签和审查状态。跨类别技能只登记一次，按主要用途放置，其余用途用标签注明。

当前各分类仅有说明，尚无实际候选或已启用技能。新增时复制 [候选记录模板](CANDIDATE_TEMPLATE.md) 到对应分类，使用易识别的文件名，例如 `plot-style.md`。

每个候选技能单独建立一份 Markdown 记录，包含：

- 名称、原始链接、作者及固定版本。
- 想解决的问题、提交人。
- 许可证与是否允许共享：待核查。
- 需要安装的软件、依赖和账号：待核查。
- 相关说明及脚本检查：待审查。
- 文件访问、联网、命令执行和安装行为：待审查。
- 审查结论、审查人和日期：待审查。
- 经审查后的小任务测试及实际结果：未运行。

没有检查的字段保持“待审查”，没有执行的测试保持“未运行”。审查通过后再迁入共享技能目录。
