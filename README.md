# 数学建模 AI 工作室

我们用 Agent 和 Skills 完成分析、建模、编程、实验与初稿，人按阶段准备工具、确认方向、核查结果、完善图表和论文。三个人不固定分成建模手、代码手和论文手。

## 五个文件夹

| 入口 | 放什么 |
| --- | --- |
| [problem](problem/README.md) | 题目、附件、必要的数据 |
| [code](code/README.md) | 模型、数据处理和绘图程序 |
| [results](results/README.md) | 实验输出和导出图表 |
| [paper](paper/README.md) | LaTeX、PDF 和获奖论文参考 |
| [skills](skills/README.md) | 技能分类、来源、审查与实测记录（当前建设重点） |

先读 [分工说明](TEAM.md)，再去 [技能目录](skills/README.md) 找自己当前要做的事。

## 日常使用

保存只改变自己的电脑；提交记录版本，推送后队友才能从 GitHub 拉取。每次完成一项小工作再同步，重要结论写进文件，不只留在聊天里。

题目、数据、实验结果、论文正文和参考 PDF 默认保留在本地。需要共享时明确指定获准文件，检查后逐项纳入 Git。当前仓库里的说明和空白技能记录可以共享；填入真实内容后仍需检查。

给 AI 的规则在 AGENTS.md。已启用技能的实际位置为 `.agents/skills`，分类和使用入口统一在 `skills`；由 Agent 维护两者的链接，不需要组员重复放两份技能。

旧版详细框架已保存在 [.archive/legacy-framework](.archive/legacy-framework/README.md)，仅供查阅，日常以本页和 TEAM.md 为准。
