# 002 共享单车：分析阶段输出

日期：2026-11-25（北京时间）。案例 002 / v1，建包日期 2026-11-23；运行编号 run-001；成员 A；mcm-plan-draft v0.1。分析已完成，模型未运行。

## 1. 题目理解

给出某一天已经记录的天气和日历信息，估计这一天的总租借次数 cnt。交付应是一套估计方法，以及它在没有参与选模型的数据上究竟错多少。单位是租借次数/日，不是独立用户人数。

这是“根据当天已知情况估计当天”的练习，不是明天需求预测，也不能直接回答应该投放多少车辆。实际租借量还可能受到车辆供给限制。

## 2. 事实、输入与待确认假设

本次读取原始 day.csv 和说明，实际检查：731 行、731 个不同日期，首尾日期 2011-01-01 和 2012-12-31；没有空白单元格；全部记录满足 casual + registered = cnt。没有据此声称所有异常或数据错误都已排除。

| 字段 | 本轮建议 | 原因 |
| --- | --- | --- |
| cnt | 目标，不能作为输入 | 要估计的每日总租借次数 |
| casual、registered | 禁用 | 两者直接拼出答案，造成信息泄漏 |
| instant | 禁用 | 记录编号，不作为业务解释变量 |
| dteday | 只用于排序、切分与画图 | 本轮不引入日期趋势模型 |
| yr | 本轮不用 | 训练集只有 2011 年，不能从它学出 2012 年的增长效应 |
| mnth、weekday、holiday、weathersit | 候选类别输入 | 数字编码不等于等距连续数值 |
| temp、hum、windspeed | 候选数值输入 | 原文件已经归一化，不能把数值直接标成摄氏度、湿度百分比或速度 |
| atemp | 本轮先不用 | 与 temp 表达相近含义；保留为后续有记录的变体 |
| season、workingday | 本轮先不用 | 与月份、星期及节假日有重叠；先控制复杂度 |

解释性假设（待确认）：当天记录的天气确实可用；两年字段定义一致；历史天气和日历关系具有一定可迁移性。后一个假设可能因系统扩张或使用习惯变化而失败，必须由留出数据检验。缺少车辆供给、站点变化等信息，不补造这些数据。

原说明中的归一化天气字段保留原值用于分析；若以后展示物理单位，先核实换算规则。本轮没有外部检索，没有新增文献引用或因果结论。

## 3. 两种候选方法与简单基准

基准：每一天都估计为训练集 cnt 的平均值。它回答“不看天气、不看日历能做到什么程度”。均值只从训练集计算。

方案 A：岭回归。可以理解为给不同天气和日历条件分配影响系数，并限制系数过度波动。类别输入编码，数值输入标准化；所有转换只在训练集拟合。优点是容易解释，局限是基础形式不善于表达复杂交互关系。

方案 B：随机森林回归。通过多组条件判断组合估计，可尝试捕捉温度与日历的非线性关系。代价是解释更困难，对时间外推也没有保证。它是否胜过 A 必须实测。

两者使用同一组输入、同一时间划分、同一指标。建议先完成基准与 A，再加入 B。未来实现可使用 Python 与 scikit-learn；这是依赖建议，尚未检查兼容性、安装或执行。随机方法拟用种子 42。

## 4. 可检验方案：尚未运行

保持题目建议的时间划分：2011 年训练（实际 365 行），2012 年 1—6 月验证（182 行），2012 年 7—12 月最终测试（184 行）。不能随机打乱混合两年。

1. 编程阶段先检查数值范围、类型、日期连续性与类别编码。异常值不能随意删除；任何处理需要记录理由。原始 CSV 保持不变。
2. 仅在训练集拟合均值、编码、标准化和模型。未知类别的处理规则预先固定；验证及测试均不得参与拟合。
3. 小范围预定比较：A 的 alpha 为 0.1、1、10；B 固定 200 棵树，仅比较 max_depth 为 4、8，min_samples_leaf 为 5。种子 42。以上参数都是建议值，不是“已验证最佳参数”。
4. 用验证集 MAE 选择方法与参数，RMSE 辅助报告；如 MAE 完全相同，优先 A，再优先较简单配置。MAE 表示平均每天差多少次，RMSE 对少数很大的错误更敏感；两者单位均为次数/日。
5. 预先约定所有负预测裁为 0，不四舍五入再评分；对所有候选采用相同规则。记录裁剪数量。
6. 选择后冻结方案，本轮不合并训练与验证重新拟合，最终测试只评估一次，同时报告基准。测试 MAE 低于基准才可说在这个留出时段有改善；这不是统计显著性或普遍有效性的证明。若没有改善，如实报告失败，不反复看测试集调参。
7. 保存逐日日期、观测、预测、数据分区、方法与版本；生成按日期的观测/预测图和残差图。配置、依赖版本、输入校验值、种子、运行命令与日志共同留存。

日期推进带来的需求增长可能使两个模型都失败。这是本次检验的局限，不能在看到最终测试结果后悄悄改成随机切分。关联和系数不能证明天气造成了多少租借变化。
