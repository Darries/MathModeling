# 001｜人员与任务匹配

建包日期：2026-11-23。版本：v1。类型：官方教学示例改编，不是比赛真题或真实人员记录。

## 题目

5 人完成 4 项任务，成本见 [data.csv](data.csv)。每项任务恰好交给一人，每人最多承担一项，目标是总成本最低。成本为抽象成本单位，不代表真实货币。

请先解释目标和约束，说明变量、假设与合适方法，比较至少两种求解思路。不要把“每项都选最便宜的人”直接当作可行方案。

第一阶段只交分析和方案，等待人工确认后再求解。第二阶段交具体安排、总成本、约束核验及计算记录；结果写入 [对应结果目录](../../results/001_2026-11-23_assignment/README.md)。

## 给测试 Agent 的提示

请使用本次指定的 Skill（未指定则记录为基线），只读取本题 README.md 和 data.csv。先用中文解释问题、列出假设和约束、比较方法并推荐方案，暂不写代码；等待我确认。不要访问 review 或联网搜索答案。没有运行就不要报告实测结果。

主测试完成后可以另做扩展：增加“某人不能执行某任务”的限制，先由人确认限制，记录为独立变体，不能沿用原题答案。

来源说明在 SOURCE.md，包含可通往答案的官方链接，由组织者核查；测试 Agent 首轮不读取。
