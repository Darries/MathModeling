# 002｜共享单车日租借量分析

建包日期：2026-11-23。版本：v1。类型：基于公开真实数据设计的练习，不是美赛真题。

## 题目

使用 data/day.csv，分析日租借量与天气及日历因素的关系，并提出两种可比较的建模方案。

本版限定为“已知当天记录的天气和日历信息，估计当天总租借量”，不是提前一天预测。若要改成未来预测，先提交变更方案并确认预测时可获得的信息。

第一阶段交付：用通俗中文解释目标，整理字段，区分可用输入与不应使用的字段，提出假设、两种候选方法、简单基准和检验办法；等待人工确认再编程。

第二阶段建议固定时间切分：2011 年训练，2012 年 1—6 月验证，2012 年 7—12 月最终测试。所有预处理仅在训练数据拟合，最终测试不能用于选模型。以 MAE 和 RMSE 比较预测误差（租借次数/日），随机方法记录种子；方案变更须记录。

输出包括实际误差、预测与观测对比图、失败与局限说明。相关性不能直接解释成因果关系。

## 数据

原样下载的日级数据和原始说明位于 data/；字段解释参见 data/Readme.txt。实际文件检查为 731 行，日期 2011-01-01 至 2012-12-31。完整来源和许可见 SOURCE.md。
