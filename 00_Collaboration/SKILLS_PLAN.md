# 技能建设计划

此文件是设计计划，不代表下列技能已经安装或通过验证。

## 目标流程

理解题目 → 模型方案 → 代码运行 → 结果验证 → 论文图表 → 论文初稿 → 一致性评审。

| 计划能力 | 输入 | 输出 | 完成检查 |
| --- | --- | --- | --- |
| 总流程协调 | 题目、允许访问的资料、任务目标 | 分阶段计划、状态记录 | 输入缺失时登记阻碍，不跳过验证 |
| 建模 | 问题定义与数据说明 | 模型交接文件 | 假设、公式、单位、基准和局限完整 |
| 代码与实验 | 已确认模型、可用数据 | 可运行代码和实验记录 | 实际运行，结果可复现 |
| 科研绘图 | 已验证实验输出 | 图表及图注 | 可重现、单位清楚、与数据一致 |
| 论文写作 | 模型、实验、核实过的引用 | Word/LaTeX 等论文初稿 | 论断能追溯到证据 |
| 一致性评审 | 同一版本的代码、模型和论文 | 差异与待修复清单 | 检查数值、符号、版本和引用 |

## 引入技能的要求

- 先用一道题跑通流程，再扩充模型类型；不要仅凭技能数量判断系统完备性。
- 自定义共享技能计划放在 `.agents/skills/技能名/SKILL.md`，按当前 Codex 支持方式验证加载。个人已安装技能不自动随仓库分发。
- 外部 GitHub 资源先检查来源、许可、实际内容、脚本行为、依赖和适用范围，再决定是否安装；普通项目不一定是可直接调用的技能。
- 记录引入资源的地址和固定版本；工具连接、账号授权及依赖需要在每位成员环境单独确认。
- 模板中的规划不能代替真实运行和结果检查。自动生成的论文交付前仍需三方评审。

参考：[Codex 技能说明](https://learn.chatgpt.com/docs/build-skills)。实施时核对当前文档和本机支持情况。
