# 每位成员的环境检查

先让仓库在每个人电脑上可用，再按所需技能安装工具。此处不是已完成的测试报告。

1. 获得仓库权限并下载，在 Codex 中打开下载的 MathModeling 文件夹。
2. 确认能读取根目录 AGENTS.md 和 START_HERE.md。
3. 在新终端运行 `git --version` 与 `python --version`，记录实际输出；报错时先解决，不照抄别人的版本。
4. 确认 Python 可用后，在项目根目录运行 `python -m venv .venv`。后续运行使用该环境，避免成员机器互相影响。
5. 按已审查技能的依赖说明安装所需包；当前项目尚无经过验证的统一依赖清单，不批量安装来历不明的依赖。
6. LaTeX、图形软件和其他插件仅在任务需要时检查。软件已安装与 Agent 能操控是两件事，需要分别验证。

## LaTeX 入门目标

论文计划使用 LaTeX 排版、输出 PDF。Agent 协助生成与修改源文件，成员不必先掌握复杂模板开发，但应能：

- 找到主文件和正文，修改文字、标题与图注。
- 编译并查看最新 PDF，找到编译日志里的错误。
- 识别图片、公式和引用的位置，提出具体修改意见。
- 检查图片清晰度、表格、公式、页数、缺失引用和版面溢出。

建议后续用一份含公式、图片、表格和引用的小模板练习。当前尚未提供或验证该模板；编译成功也不等于数学内容正确。
