# 论文与参考

后续可使用 `main.tex` 作为入口，章节放在 `sections/`，编译 PDF 放在 `build/`；这些是约定，当前尚未创建论文或验证编译。

获奖论文放在 [references](references/README.md)。它们用于学习结构和表达，不作为本团队实验结果，也不直接复制其论述。

Agent 协助生成和修改源文件；成员掌握打开、编译、改文字和图注、查看报错、检查 PDF 即可开始协作。公式与结论仍需人工核验。

为 AI 使用保留真实记录，可存于本目录下的 `ai_usage/`，正式提交前据此整理披露。

正文、PDF 和完整对话等新增内容默认被 Git 忽略，共享前逐项确认。
